# Contributing / Colaborar

Please report macOS version, Intel Mac model, Horos build/version, installation step, and the **exact non-sensitive error text**. Never upload patient DICOM studies, identifiers, private logs, or proprietary Horos binaries. Use test data only.

Before proposing a patch, test with an **independent copy** and verify rollback. Do not broaden supported versions without examining their binary layouts. Changes to signing, quarantine, or permissions must explain security trade-offs.

Contributions are welcome through GitHub Issues and Pull Requests after the repository is published.
